GLiNER: Find Any Word in Text

Extract custom words and tags instantly without training a new model
Step 1
Read Text & Tags
Pass your text and any custom tag names into the model together.
[Labels] + [Your Text]
Step 2
Find Word Phrases
The model reads each phrase and remembers where it starts and ends.
Phrase = [Start Word ... End Word]
Step 3
Convert to Meanings
Phrases and tag names are mapped into numbers representing their meaning.
Meaning(Phrase) ↔ Meaning(Tag)
Step 4
Match & Highlight
When a phrase matches a tag above your cutoff score, it gets highlighted.
Match Score > Cutoff → Found

Simple Python Code Examples

Copy and paste these snippets to run GLiNER and TabPFN in your own Python projects
from gliner import GLiNER

# 1. Load the model
model = GLiNER.from_pretrained("urchade/gliner_small-v2.1")

# 2. Pick any tags you want to find
labels = ["contracting_party", "liability_cap", "penalty_rate"]

# 3. Find matched words and their character positions
entities = model.predict_entities(contract_text, labels, threshold=0.45)
for ent in entities:
    print(f"{ent['label']}: '{ent['text']}' (Confidence: {ent['score']:.2f})")
